# FinTech LLM System 🚀

An AI-powered, real-time, risk-aware FinTech system built using LLMs, multi-agent architecture, fraud detection, and high-frequency trading logic.

## Tech Stack
- Python, FastAPI, Docker
- LLMs: GPT-4, Bloom, Mixtral (later)
- Market APIs: Yahoo Finance, Binance, EDGAR
- GraphDB (Neo4j), MongoDB, Redis
- Frontend: Next.js + Tailwind CSS (later)
